## 📋 О боте

**ArtyStaff Bot** — это мощный Discord-бот для автоматизации управления персоналом проекта FT. Бот интегрирован с **Google Таблицами** и **Google Формами**, что позволяет вести полный учёт сотрудников, наказаний и статистики.

### 🎯 Основные возможности

| Функция | Описание |
|---------|----------|
| 👥 **Состав** | Автоматическое обновление состава сотрудников в реальном времени |
| ⚖️ **Наказания** | Выдача/снятие варнов и устников с системой баллов |
| 📊 **Статистика** | Просмотр баллов, варнов, устников и должности сотрудника |
| 🔐 **Безопасность** | Автоматическое удаление доступа к таблице и форме при увольнении |
| 📝 **Учёт** | Автоматическая запись всех действий в каналы Discord |
| 🎓 **Повышения** | Автоматическая смена ролей и обновление состава при повышении |
